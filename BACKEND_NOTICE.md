# Server implementation boundary

This repository publishes the ShuProphet Data Studio frontend and public integration/deployment materials. New server implementations are distributed separately by the project owner and are excluded from this public repository.

The `backend/`, `private/`, `.private-release/`, runtime data and local secrets must not be committed. Build and deployment require an authorized private engine delivery.

Earlier versions of this repository included backend source. Removing those files from the current tree does not remove Git history or revoke licenses already granted for previously published code. The existing repository license continues to apply to material previously released under it.
